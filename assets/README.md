# MingliGo logo assets

These files are the source assets for MingliGo runtime and README branding.
Keep the palette defined here as the single direction for this repository.

`logo.svg` is the product mark: a solid Jilan / indigo-blue yin-yang fish.
The eye dot is intentionally merged into the body color, so the mark stays a
single high-perception-saturation block at small sizes. `logo-dark.svg` is
used for dark color schemes. The horizontal lockups are provided for
documentation covers and presentation material.

## Palette

| Role | Hex |
|---|---|
| Jilan / primary mark | `#006BCF` |
| Light lockup text | `#111827` |
| Dark lockup text | `#F8FAFC` |

## Files

| File | Use |
|---|---|
| `logo.svg` | Canonical mark |
| `logo-dark.svg` | Canonical mark for dark backgrounds |
| `logo-horizontal.svg` | Light horizontal lockup |
| `logo-horizontal-dark.svg` | Dark horizontal lockup |
| `logo-16.png` through `logo-1024.png` | Raster exports |
| `favicon.png` | Compact 32 px favicon export |
